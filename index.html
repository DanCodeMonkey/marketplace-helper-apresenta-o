Por que o lucro do vendedor some sem ele perceber

Cada venda carrega comissão, frete, impostos e custo operacional. Somados, eles consomem boa parte do preço, e o vendedor só vê o resultado no fechamento do mês.

Exemplo de um anúncioR$
Preço de venda100,00
Custo do produto− 45,00
Comissão do Mercado Livre− 14,00
Frete subsidiado− 18,00
Impostos e custo operacional− 10,00
Lucro líquido (margem de 13%)13,00

Valores ilustrativos. Uma variação no frete já muda a margem.

Do IoT ao frete calculado

1O dispositivo mede largura, altura, comprimento e peso (hoje simulado na tela /medir).
2As medidas são salvas por SKU na API — POST /produtos/medidas.
3A API calcula o peso cubado L × A × C ÷ 6000 e adota o maior entre real e cubado.
4Com o preço de venda, consulta a tabela oficial de frete do Mercado Livre → frete real.
5Compara o frete real com o cobrado hoje pelo ML e sinaliza divergências.
6Dashboard, Produtos e a lista de anúncios mostram onde o frete está divergente.

Frete divergente: o diferencial

Com as medidas do produto, a plataforma calcula o frete real pela cubagem e compara com o cobrado hoje pelo Mercado Livre. A diferença revela dimensões mal cadastradas no anúncio.

Mesmo produtoFrete
Cobrado hoje (dimensões declaradas)R$ 10,00
Real (medidas + cubagem)R$ 58,75
Divergência+ R$ 48,75

Subdeclarado

Frete real acima do cobrado: risco de cobrança extra do Mercado Livre.

Superdeclarado

Frete real abaixo do cobrado: o vendedor paga frete a mais.

Onde aparece

Em Produtos, no Dashboard e como filtro na lista de anúncios.

Alerta quando a diferença é de R$ 2 ou maisImplementado na web

API web e regras de negócio

Base técnica

  • Node.js, Express e Prisma ORM
  • SQLite com migrações versionadas (troca futura para PostgreSQL)
  • MVC com camada de serviços
  • Interface responsiva (menu lateral, planilha/cards)
  • Sincronização com o ML às 00:00 e 12:00

Segurança

  • Senhas com hash bcrypt
  • Tokens do ML cifrados com AES-256-GCM
  • Sessão por cookie assinado
  • Dados isolados por usuário
