O lucro some sem o vendedor perceber

Cada venda carrega comissão, frete, impostos e custo operacional. Somados, consomem boa parte do preço — e o vendedor só vê o resultado no fechamento do mês.

Regras de negócio e cálculo

Comissão e frete vêm da API do ML; o custo do produto e as alíquotas são do vendedor. O cálculo roda sob demanda, então mudar uma alíquota reflete na hora.

Lucro e margem por anúncio

base = precoPor (promoção) ou precoDe
impostos = base × (ICMS + IPI + DIFAL + custo op.) ÷ 100
lucro = base − custo − comissão − frete − impostos
margem = lucro ÷ base × 100 · custo ML = comissão + frete

Frete real pela cubagem

cubagem = L × A × C (cm) ÷ 6000
peso considerado = maior(peso real, cubagem)
frete real = tabela ML(considerado, preço)
divergente quando |frete real − frete cobrado| ≥ R$ 2

Frete divergente: o diferencial

Com as medidas do produto, a plataforma calcula o frete real e compara com o cobrado hoje pelo ML. A diferença revela dimensões mal cadastradas no anúncio.

Mesmo produtoFrete
Cobrado hoje (dimensões declaradas)R$ 10,00
Real (medidas + cubagem)R$ 58,75
Divergência↑ R$ 48,75

Subdeclarado

Frete real acima do cobrado: risco de cobrança extra do Mercado Livre.

Superdeclarado

Frete real abaixo do cobrado: o vendedor paga frete a mais.

Onde aparece

Em Produtos, no Dashboard e como filtro na lista de anúncios.

Do IoT ao frete calculado

1O dispositivo mede largura, altura, comprimento e peso (hoje simulado na tela /medir).
2As medidas são salvas por SKU na API — POST /produtos/medidas.
3A API calcula o peso cubado L × A × C ÷ 6000 e adota o maior entre real e cubado.
4Com o preço de venda, consulta a tabela oficial de frete do Mercado Livre → frete real.
5Compara o frete real com o cobrado hoje pelo ML e sinaliza divergências.
6Dashboard, Produtos e a lista de anúncios mostram onde o frete está divergente.

API web e segurança

Base técnica

  • Node.js, Express e Prisma ORM
  • SQLite com migrações versionadas (troca futura para PostgreSQL)
  • MVC com camada de serviços
  • Interface responsiva (menu lateral, planilha/cards)
  • Sincronização com o ML às 00:00 e 12:00 (node-cron)

Segurança

  • Senhas com hash bcrypt
  • Tokens do ML cifrados com AES-256-GCM
  • Sessão por cookie assinado
  • Dados isolados por usuário (multiusuário)
